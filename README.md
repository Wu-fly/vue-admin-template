| 目录 | 职责 | 层级 |
|------|------|------|
| `api/` | 后端接口封装与管理 | 数据层 |
| `assets/` | 静态资源存储 | 资源层 |
| `components/` | 可复用 UI 组件 | 组件层 |
| `icons/` | 图标资源管理 | 资源层 |
| `layout/` | 整体布局结构 | 布局层 |
| `router/` | 路由配置与导航 | 控制层 |
| `store/` | 全局状态管理 | 状态层 |
| `styles/` | 全局样式定义 | 样式层 |
| `utils/` | 通用工具函数 | 工具层 |
| `views/` | 页面视图组件 | 视图层 |
